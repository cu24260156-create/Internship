Privacy & Security

  • ✅ Zero Mandatory Logins: Guest users can freely browse roadmaps, search portals, and ask questions without providing any personal data.
  • ✅ Backend Key Protection: All API keys, Google credentials, and database operations are held securely on the backend server.
  • ✅ Strict User Isolation: SQLite queries enforce parameterized user-ownership checks (`user_id = ?`). One user cannot access another's chat sessions, bookmarks, or resume data.
  • ✅ In-Memory Resume Parsing: Resumes submitted to the ATS checker are processed strictly in-memory and are immediately cleared.
